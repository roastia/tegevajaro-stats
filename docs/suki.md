# てげ好き（テゲバの好きなところ）の受付と掲載

## 流れ
1. テゲサポが /tegesuki/ の下の「書き込む」か「教えて！」の #suki から送る（どちらも `src/components/SukiForm.astro`。お題をドロップダウンで選ぶと書き出しが入る。試合の日・翌日は「今日の試合」「昨日の試合」のお題が先頭に出る）（ニックネーム任意・本文600字まで・同意のチェック・Turnstile）。
   受付は Worker の `POST /api/suki` → D1 の `suki_submissions`（公開しない受け箱）。
2. 取り出す（ユーザーが Mac で）：`npm run suki:pull` → `private/suki-inbox.json`（Git には入らない）。まだ処理していない声だけが1行ずつ表示される。
3. Claude が `node tools/suki.mjs new` の1行表示だけを読み、1件ずつ「載せる（タグ）／少し直す（直した文）／外す」を短く出す。
4. OK が出たら、Claude が Mac で `node tools/suki.mjs add 8:選手,応援 9:ゴール --skip 10` を実行（番号・日時の転記・形のチェック・コミットまで自動）。本文を直すときは先に `private/suki-fix.json` に `{"8": "直した本文"}` を置く。
5. 公開（ユーザーが Mac で）：`npm run suki:publish` → push と、D1 の status を `approved`・`rejected` にする印付け（メモ。サイトの表示には使わない）。

### 手間（トークン）を減らす決まり
- 受け箱のファイル全体や suki.json を読まない。`new` の1行表示だけで判断する。
- データだけの変更なので、ふだんはビルドや画面の確認をしない（形のチェックは `add` が行う。サイトのビルドは push 後に GitHub が行う）。
- 事実の確かめ（検索）は、スコア・日付・記録など、まちがうと困る具体的なことが書かれているときだけ。
- 返事は「#番号 判断 タグ（直すときは直した文）」の短い一覧と、OK のあとの公開コマンドだけ。

## 載せる形（src/data/suki.json）
```json
{ "id": "k1", "no": 2, "date": "2026-11-20", "time": "21:03", "nickname": "テゲ太郎", "body": "本文（改行そのまま）", "tags": ["応援", "スタジアム"] }
```
- id は `k` ＋ D1 の id。載せた声は、テゲサポの記録として残す（掲載をやめる依頼の対象にしない。投稿のときに同意をもらっている）。date・time は、その人が送信した日時（Worker が受け取った時刻。日本時間）。`npm run suki:pull` の date・time をそのまま写す（created_at は UTC なので、そのまま使わない）。
- no はスレのレス番号。>>1 はテゲスタ！のあいさつ（ページに固定）なので、声は 2 から、載せた順に続けて付ける（あとから変えない。X でポストしたリンク #r〇 がずれるため）。
- 返信や、ほかのレスにつなげるしくみはない（ひとつひとつが独立した声）。本文に `>>12` のような書き方があれば、載せるときに外す。
- 言葉でさがすと、見つかった言葉をピンクで目立たせる（ひらがな・カタカナのちがいは無視）。
- 一覧は20・50・100件ずつ（選んだ件数はその端末に覚える）。一覧を読み進めると、右下に「一覧の先頭へ」が出る（さがす欄に戻る）。それより多いときはページ送り。#r12 で来たら、そのレスのあるページを開く。
- nickname が空なら「テゲサポさん」と出す。
- tags は `src/lib/suki.js` の SUKI_TAGS から（選手・ゴール・応援・スタジアム・思い出・遠征・宮崎・クラブ・家族・仲間・未来）。1件に1〜3個。

## 直し方の決まり
- 載せない：悪口・特定の人を傷つける内容、個人の情報（本名・住所・連絡先など）、宣伝、テゲバと関係のない内容。
- 少し直す：誤字・言いまわしを読みやすく。選手・相手チームへのきつい言葉はやわらげる。意味や気持ちは変えない。
- 直したかどうかの印は付けない（ページの下に「一部の表現を整えていることがあります」とだけ書いている）。
- 事実の誤り（スコア・日付など）は直すか、その部分を外す（「間違いがないことが大切」）。

## いいね！
- 各レスの「いいね！」は Worker の `/api/likes`（GET で数の一覧、POST `{id:"r12", on}`）。D1 は hearts テーブルを共用（id は `r`＋番号。1つのIPで1日1回）。

## X でポスト
- 画像なし。本文（50字を越えるときは、50字までの文の終わり（。！？）で切る。なければ読点の前、それもなければ50字で切って「…」。あとに「（続きは「てげ好き」で）」。かぎかっこ・名前は付けない）＋ #てげ好き ＋いつものハッシュタグ、URL は `/tegesuki/#r〇`（レス番号）。
- ポストする人は、X の画面で自分のひとことを書き足す。
