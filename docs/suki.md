# てげ好き（テゲバの好きなところ）の受付と掲載

## 流れ
1. テゲサポが /tegesuki/ の下の「書き込む」か「教えて！」の #suki から送る（どちらも `src/components/SukiForm.astro`。お題ボタンで書き出しが入る。試合の日・翌日は「今日の試合」「昨日の試合」のお題が先頭に出る）（ニックネーム任意・本文600字まで・同意のチェック・Turnstile）。
   受付は Worker の `POST /api/suki` → D1 の `suki_submissions`（公開しない受け箱）。
2. 手元に取り出す：`npm run suki:pull` → `private/suki-inbox.json`（Git には入らない）。
3. Claude が1件ずつ「そのまま載せる／少し直す（直した文の案）／外す」とタグの案を一覧で出す。
4. OK が出たものだけ `src/data/suki.json` に、載せる順に番号（no）を付けて足して push。毎日のビルドで /tegesuki/ のスレに並ぶ。
5. 載せた・外したの印は D1 の status を `approved`・`rejected` に（メモ。サイトの表示には使わない）。

## 載せる形（src/data/suki.json）
```json
{ "id": "k1", "no": 2, "date": "2026-11-20", "time": "21:03", "nickname": "テゲ太郎", "body": "本文（改行そのまま）", "tags": ["応援", "スタジアム"] }
```
- id は `k` ＋ D1 の id。載せた声は、テゲサポの記録として残す（掲載をやめる依頼の対象にしない。投稿のときに同意をもらっている）。date・time は、その人が送信した日時（Worker が受け取った時刻。日本時間）。`npm run suki:pull` の date・time をそのまま写す（created_at は UTC なので、そのまま使わない）。
- no はスレのレス番号。>>1 はテゲスタ！のあいさつ（ページに固定）なので、声は 2 から、載せた順に続けて付ける（あとから変えない。>>番号 の引用がずれるため）。
- 本文の `>>12` は、そのレスへのリンクになる（ある番号だけ）。レスの下には、そのレスに >>番号 でつながっている声を「つながる声：」として並べる（「返信」とは呼ばない。会話ではなく、関係のある声をむすぶしくみ）。つながる先が載っていない声は、>>番号 を外すか、先に元の声を載せる。
- 言葉でさがすと、見つかった言葉をピンクで目立たせる（ひらがな・カタカナのちがいは無視）。
- 一覧は20・50・100件ずつ（選んだ件数はその端末に覚える）。それより多いときはページ送り。#r12 で来たら、そのレスのあるページを開く。
- nickname が空なら「テゲサポさん」と出す。
- tags は `src/lib/suki.js` の SUKI_TAGS から（選手・ゴール・応援・スタジアム・思い出・遠征・宮崎・クラブ・家族・仲間・未来）。1件に1〜3個。

## 直し方の決まり
- 載せない：悪口・特定の人を傷つける内容、個人の情報（本名・住所・連絡先など）、宣伝、テゲバと関係のない内容。
- 少し直す：誤字・言いまわしを読みやすく。選手・相手チームへのきつい言葉はやわらげる。意味や気持ちは変えない。
- 直したかどうかの印は付けない（ページの下に「一部の表現を整えていることがあります」とだけ書いている）。
- 事実の誤り（スコア・日付など）は直すか、その部分を外す（「間違いがないことが大切」）。

## いいね！
- 各レスの「いいね！」は Worker の `/api/likes`（GET で数の一覧、POST `{id:"r12", on}`）。D1 は hearts テーブルを共用（id は `r`＋番号。1つのIPで1日1回）。

## X でポスト
- 画像なし。本文（>>番号 は外す。50字を越えるときは、50字までの文の終わり（。！？）で切る。なければ読点の前、それもなければ50字で切って「…」。あとに「（続きは「てげ好き」で）」。かぎかっこ・名前は付けない）＋ #てげ好き ＋いつものハッシュタグ、URL は `/tegesuki/#r〇`（レス番号）。
- ポストする人は、X の画面で自分のひとことを書き足す。
