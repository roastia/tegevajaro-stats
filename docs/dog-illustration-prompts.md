# 選手の犬イラスト：ChatGPT 用プロンプト

テゲバ非公式ランキングの「選手の称号」などで使う、選手ごとの犬のイラストを ChatGPT（画像生成）で作るためのプロンプトです。

## 先に守ること（権利まわり）
- **ジャーロくんに似せない。** ジャーロくんはクラブの公式マスコット（クラブの著作物・商標）なので、ピンク色の犬、ジャーロくんの顔・耳・服装の特徴、名前は使いません。このサイトの犬は**オリジナルの別キャラクター**です。
- **選手の顔や見た目（髪型・ひげ・体格の写真的な特徴）を写さない。** 特徴は「ポジション・背の高さ・出身地」という変わらないデータだけから作ります。選手の写真を ChatGPT に渡さないでください。
- **クラブのユニフォーム・エンブレム・スポンサーロゴを描かせない。** 服は無地の白いシャツ＋ポジション色のバンダナにします。
- **全員を同じ構図・同じ大きさ・同じ装飾の量**にする（見せ方で優劣をつけない）。王冠・金色の光など「すごさ」を強調する飾りは使いません。
- 画像には**文字・数字を入れない**（背番号も入れない）。背番号・称号・年齢のように変わる情報を描かないので、一度作った画像はずっと使えます。

## 使い方
1. ChatGPT の新しい会話で、まず「共通プロンプト」を送ります。
2. 続けて、選手ごとのプロンプトを1人ずつ送ります（1枚できたら次へ）。
3. 絵柄がずれてきたら、もう一度「共通プロンプト」を送り直します。
4. できた画像は、選手ごとに書いてある「保存先」（Jリーグ公式の選手IDの名前。背番号が変わっても変わりません）に保存し、Claude に「選手イラストを入れて」と伝えてください。

## 共通プロンプト（最初に1回送る）

```
これから、サッカーファンサイト用の「犬の選手キャラクター」を1匹ずつ描いてもらいます。全員を次の共通ルールでそろえてください。

【絵柄】
・フラットな2Dイラスト。太めの丸い線、シンプルな形、やわらかい配色。かわいくて親しみやすいゆるキャラ風。
・全身、正面から少し斜め。頭が大きめの2.5頭身。
・背景は無地の白（または透過）。正方形 1024×1024。キャラクターは中央に、上下左右に余白をとる。
・影は控えめ、グラデーションは使わない。全員同じ線の太さ・同じ大きさ。

【服装・小物】
・無地の白いTシャツ（ロゴ・ストライプ・スポンサー表記なし）。
・首にポジション色のバンダナ。
・サッカーボールは白黒の一般的なデザイン。

【描かないもの】
・実在の人物の顔や似顔絵、実在のクラブのユニフォーム・エンブレム・マスコット（ピンク色の犬のマスコットに似せない）。
・王冠、トロフィー、金色の光などの「格付け」を感じる飾り。
・文字や数字（背番号・名前・ロゴを含む）。
```

## 選手ごとのプロンプト

称号・年齢・背番号のように変わる情報は使っていないので、一度作った画像は作り直す必要がありません。使っているのは、ポジション（バンダナの色とポーズ）・身長（犬の大きさ）・出身地（宮崎出身だけワッペン）です。顔や見た目は使っていません。新しい選手が加入したら `node tools/dog_prompts.mjs` を実行すると、その選手のプロンプトが追加されます（既存の選手のプロンプトは変わりません）。
