# 選手の犬イラスト：ChatGPT 用プロンプト

テゲバ非公式ランキングの「選手の称号」などで使う、選手ごとの犬のイラストを ChatGPT（画像生成）で作るためのプロンプトです。

## 先に守ること（権利まわり）
- **ジャーロくんに似せない。** ジャーロくんはクラブの公式マスコット（クラブの著作物・商標）なので、ピンク色の犬、ジャーロくんの顔・耳・服装の特徴、名前は使いません。このサイトの犬は**オリジナルの別キャラクター**です。
- **写真は特徴を読み取るためだけに使う。** 写真を見て髪型・眉・目つき・表情などの特徴を言葉にし、その言葉だけをプロンプトに入れます。写真そのものは ChatGPT に渡しません。本人に似せた絵は似顔絵と同じ扱いになりうるので、公開前にクラブへ使ってよいか確認するのが安全です。
- **クラブのユニフォーム・エンブレム・スポンサーロゴを描かせない。** 服は無地のTシャツ＋バンダナにします（白黒の線画なので色は付けません）。
- **全員を同じ構図・同じ大きさ・同じ装飾の量**にする（見せ方で優劣をつけない）。王冠・金色の光など「すごさ」を強調する飾りは使いません。
- 画像には**文字・数字を入れない**（背番号も入れない）。背番号・称号・年齢のように変わる情報を描かないので、一度作った画像はずっと使えます。

## 使い方
1. ChatGPT の新しい会話で、まず「共通プロンプト」を送ります。
2. 続けて、選手ごとのプロンプトを1人ずつ送ります（1枚できたら次へ）。
3. 絵柄がずれてきたら、もう一度「共通プロンプト」を送り直します。
4. できた画像は背景が透過になっているか確かめてから、選手ごとに書いてある「保存先」（Jリーグ公式の選手IDの名前。背番号が変わっても変わりません）に保存し、Claude に「選手イラストを入れて」と伝えてください。

## 共通プロンプト（最初に1回送る）

```
これから、サッカーファンサイト用の「犬の選手キャラクター」を1匹ずつ描いてもらいます。全員を次の共通ルールでそろえてください。

【絵柄】
・白黒の線画イラスト。黒い線だけで描き、色・グレーの塗り・トーン・グラデーション・影は使わない（中は白抜き）。ただし黒髪を指定したときだけ、髪を黒のベタ塗りにしてよい。
・線は太めで均一、角の丸いやわらかい線。シンプルな形で、かわいくて親しみやすいゆるキャラ風。
・全身、正面から少し斜め。頭が大きめの2.5頭身。
・背景は透過（透明）のPNG。背景色・地面・枠・影は描かない。正方形 1024×1024 で、キャラクターは中央に、上下左右に余白をとる。
・全員同じ線の太さ・同じ大きさ。

【服装・小物】
・無地のTシャツ（ロゴ・ストライプ・スポンサー表記なし）。
・首にバンダナ。
・サッカーボールは一般的な五角形・六角形の線のデザイン。

【描かないもの】
・実在のクラブのユニフォーム・エンブレム・マスコット（ピンク色の犬のマスコットに似せない）。
・王冠、トロフィー、光のエフェクトなどの「格付け」を感じる飾り。
・文字や数字（背番号・名前・ロゴを含む）。
```

## 選手ごとのプロンプト

称号・年齢・背番号のように変わる情報は使っていないので、一度作った画像は作り直す必要がありません。使っているのは、ポジション（ポーズ）・身長（犬の大きさ）・出身地（宮崎出身だけワッペン）と、写真から読み取った見た目の特徴（入れた選手のみ）です。白黒の線画なので色の指定はありません。新しい選手が加入したら `node tools/dog_prompts.mjs` を実行すると、その選手のプロンプトが追加されます（既存の選手のプロンプトは変わりません）。
