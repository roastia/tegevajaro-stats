# チャントのページ

## 決まっていること
- メニューに「チャント」を足す。位置は「みやざき情報」の前（注目トピック・ランキング・選手・ハイライト・日程・チャント・リンク・みやざき情報）
  - スマホのメニューは今、2段目が「日程（1マス）・リンク（1マス）・みやざき情報（2マス）」。チャントを足すときは、みやざき情報を1マスにするか3段目に回すかを見た目で確かめて決める
- ページには「チャント：宮崎ブーゲンビリーバー」と必ず書き、団体の X・YouTube・Instagram にリンクする
- **宮崎ブーゲンビリーバーを正とする**（2026-11-12 に決定）。曲名・原曲・アーティスト・コールの表記は、いちばん新しい歌詞カード（選手は 9/20 時点、チームは 26/27）の書き方にそろえる。カードに書いていない原曲を、ほかで調べて足さない
- 内容はブーゲンビリーバーの発表（歌詞カード・紹介ポスト・YouTube）だけを元にする。歌詞を変えたり、録音したりしない
- 例外：ひょっとこ（カードにない昔からのチャント。直接フリーキックなどのチャンスで歌う）は、本人の希望で載せる
- 音源は YouTube へのリンク（埋め込まない。外部の読み込みはしないため）

## 今のページ（src/pages/chants.astro ＋ src/data/chants.csv）
- 2026-11-10 に、歌詞なしで公開する形で作った（歌詞はブーゲンビリーバーの歌詞カードの X ポストへリンク）
- chants.csv の列：id・kind（player・staff・team・memorial・movie・card）・name・call・song・artist・youtube（card は X のポストの URL）・rec（ブーゲンビリーバー以外の録音のときだけ、その出どころ。ページに「音源」として出す）
- 載せているのは、26/27 の歌詞カードにあるチャントだけ。2025 のカードだけにあるチーム（テゲバVole!・アレアレオ・VAMOS テゲバ・パモパモ テゲバ・宮交シティ）は載せていない
- 音源はブーゲンビリーバーの YouTube（旧チャンネル @Bougainbeliever と、2025年からの「宮崎ブーゲンビリーバー2025」）。ブーゲンビリーバーの音源がないチームチャントだけ、TEGEmania channel（2020年の録音）にリンクする：We are テゲバ（題は「Oi-SKA」）・ひょっとこ
- 原曲はカードにあるものだけ。曲名がなくアーティストだけのもの（グロリアス：東京スカパラダイスオーケストラ）は、アーティストだけ出す。カードに原曲がないもの（宮崎の誇り・大脱走・forza！宮崎・テゲベスト・Go West・GO！GO！テゲバジャーロ・トリノ・エンターテイナー）は空けている
- 土信田 悠生選手：9/20 のカードにはないが、ブーゲンビリーバーの紹介ポスト（2026-01-28）と YouTube があるので載せている
- 塚本 一咲選手：9/20 のカードにあるが、ヴィアティン三重へ期限付き移籍中で今の選手ではないので載せていない
- TEGEmania channel の題と同じ曲：Emotions＝夢の舞台へ、テゲバ ole!＝テゲバVole!、Oi-SKA＝We are テゲバ、バモバモス＝パモパモ テゲバ（2025 のカードだけなので載せていない）。カモンテゲバ・テゲバの男・テゲバのゴールが見たい・パーフェクト・テゲバ・ale テゲバ・ゴール！ゴール！テゲバジャーロ！！はどのカードにもない
- soccer-chant.com は載せない（原曲・日付・出典がなく、録音の出どころもわからない）
- スマホのメニューは、2段目を「日程・チャント・リンク・みやざき情報」の1マスずつにした
